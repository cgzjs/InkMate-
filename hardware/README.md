# 硬件资料

## 当前收录

`reference/BB2V1.step` 是当前外壳所依据的去四针排针版本 PCB 装配参考，由维护者提供。它用于外形、孔位和器件高度核对，不包含实际屏幕实体，屏幕按近似测量建模。

目前没有将下载目录里不同日期、不同 Board / PCB 名称的 Gerber、BOM 或旧 `.epro2` 项目混入本目录。尚不能证实这些文件和当前实物完全对应。

## 待补齐的生产资料

- 当前版原理图 PDF 与可编辑原理图源文件。
- 当前版可编辑 PCB 工程。

- 对应 PCB 版本号、尺寸、板厚和器件变更说明。

这些文件应完成一致性及 DRC / 电气检查之后再发布。**目前不应仅根据本目录下单生产。**

## 固件使用的主要引脚

| 信号 | 经典 ESP32 GPIO |
| --- | --- |
| 屏幕 DIN / MOSI | 23 |
| 屏幕 CLK | 18 |
| 屏幕 CS | 5 |
| 屏幕 DC | 17 |
| 屏幕 RST | 16 |
| 屏幕 BUSY | 19 |
| PCF8563 SDA | 21 |
| PCF8563 SCL | 22 |
| NEXT / SW4 | 32 |
| PREV / SW8 | 25 |
| OK / SW5 | 33 |
| BACK / SW2 | 26 |
| 电机驱动 | 27 |
| 电池电压采样 | 34 |
| 充电状态 / 完成 | 35 / 39 |

这是从当前固件读取的映射，不是对任意旧 PCB 的接线保证。屏幕 RST 是外设复位，ESP32 复位是 EN，两者不可混淆。

串口下载使用 UART0，CH340 的 TX 接 ESP32 RX0，RX 接 ESP32 TX0，并共地。信号必须是 3.3V 电平；EN / GPIO0 的下载时序见固件使用说明。

## 供电与机械安全

使用合适的单节锂电池、绝缘和保护措施，不要挤压电芯，不要短路，不要让屏幕排线压在锐边或螺柱下面。USB-C、充电芯片和电源路径应结合最终原理图验证，不根据机械截图判断供电完整性。

STEP 内的第三方零件模型不随本项目被重新授权。权限说明见仓库根目录的第三方说明。

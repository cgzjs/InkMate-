# 硬件资料

## 当前收录

`reference/BB2V1.step` 是外壳所依据的 PCB 装配模型，已去除四针排针，用于查看板形、安装孔和器件高度。屏幕与四颗日常按键朝向正面，电池放在背面。

## 主要组成

- ESP32 主控，适配 4MB / 16MB Flash。
- CZ04 墨水屏接口，212 × 104 绘图区域。
- PCF8563 实时时钟，I²C 连接。
- NEXT / PREV / OK / BACK 四颗功能键，以及 EN、GPIO0 维护按键。
- 单节锂电池、USB-C 充电电路、电池电压采样和充电状态输入。
- GPIO27 控制的振动电机驱动。

## 固件使用的主要引脚

| 信号 | 经典 ESP32 GPIO |
| --- | --- |
| 屏幕 DIN / MOSI | 23 |
| 屏幕 CLK | 18 |
| 屏幕 CS | 5 |
| 屏幕 DC | 17 |
| 屏幕 RST | 16 |
| 屏幕 BUSY | 19 |
| PCF8563 SDA | 21 |
| PCF8563 SCL | 22 |
| NEXT / SW4 | 32 |
| PREV / SW8 | 25 |
| OK / SW5 | 33 |
| BACK / SW2 | 26 |
| 电机驱动 | 27 |
| 电池电压采样 | 34 |
| 充电状态 / 完成 | 35 / 39 |

屏幕 RST 连接 GPIO16，ESP32 自身复位使用 EN。

串口下载使用 UART0，CH340 的 TX 接 ESP32 RX0，RX 接 ESP32 TX0，并共地。信号必须是 3.3V 电平；EN / GPIO0 的下载时序见固件使用说明。

## 供电与机械安全

电池位于 PCB 背面，使用绝缘材料与板上焊点隔开，并为电池和导线留出空间。屏幕排线沿面盖预留区域弯折，避开螺柱和锐边。

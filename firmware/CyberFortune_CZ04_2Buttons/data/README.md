# Vocabulary data

`vocab_cet6.tsv` and `vocab_ielts.tsv` are compact device packs generated from
the WordTyper vocabulary repository. That repository derives its lists from
ECDICT under the MIT License. CET and IELTS names are used only to describe
the source tags and do not imply endorsement by an examination body.

Source: https://github.com/grhliu/wordtyper-vocabularies

Original and derived data license: MIT. Copyright (c) 2025 Linwei.

The files in this directory belong in the LittleFS partition. A normal OTA
application update does not install them or change the partition table; use
the matching full-flash image for first installation of the current release.

The complete upstream MIT text is retained in `LICENSE-WordTyper.txt`.
The project's lack of a new software license does not change this data license.

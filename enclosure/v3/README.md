# 墨伴轻薄外壳 v3

![外壳与面盖](../../docs/images/enclosure_preview.png)

本目录只提供当前 v3；源代码中的 `reference_v2` 是几何回归检查用的两个小参考文件，不是旧版打印套件。v3 基于实际 v2 试装反馈放宽屏幕配合、重新设计压框安装、缩短键帽裙边并放大刻字。

## 文件怎么选

| 目录 | 用途 |
| --- | --- |
| `print/` | 七个独立、已放置打印方向的 STL，直接交给切片软件 |
| `step/` | 整壳及各零件可编辑 STEP；不包含超过网页上传限制的整板装配模型 |
| `source/` | CadQuery 生成和检查脚本、参数与比较参考 |
| `DESIGN_NOTES.md` | 原始英文几何与装配记录 |

首次打印需要底壳、面盖、屏幕压框和四颗键帽，各一件。已有 v2 底壳时，只需重新打印其余六件。使用毫米、100% 比例，不要为了修正配合整体缩放，否则孔距和屏幕位置都会改变。

## 关键尺寸

- 主体 87.1 × 56.4 × 14.8 mm，不含挂扣；含突出键帽最大厚度约 16.2 mm。
- 近似屏幕 59 × 30 × 1 mm，容纳槽 60.2 × 31.2 mm，可视窗口 55 × 26 mm。
- 屏幕槽每侧名义余量 0.6 mm，左侧保留排线弯折空间。
- 键帽导向直径 6.6 mm，面盖孔径 7.6 mm。就位后顶部约突出 1.2～1.4 mm。
- 屏幕压框直接从内侧落入四个圆形安装位，不再插入精细方槽。
- 压框 M1 通孔直径 1.4 mm，面盖塑料导孔 0.95 mm、入口 1.4 mm；二者不同是为了分别满足穿过与咬合。
- M1 直接拧塑料，不做打印螺纹，不装螺母。建议 M1 × 2 mm，最大 2.5 mm，非沉头、头径至少 1.8 mm；模型检查的头部包络直径为 2.0 mm、高 0.7 mm。

## 装配顺序

1. 清除孔口和活动边缘毛刺，先从内侧放入四颗键帽，逐颗检查活动是否顺畅。
2. 在屏幕外边框放置约 0.2 mm 柔性绝缘缓冲，不覆盖显示有效区或压住 FPC 接合处。
3. 将屏幕放入槽内，整理左侧排线，避免锐角折叠、过度拉伸或用力压玻璃。
4. 放入压框，让它落在四个安装位上。压框不是靠拧螺丝强拉到位。
5. 最好先不装屏幕，手工试攻 M1 塑料导孔。若打印封孔，应谨慎清孔，不要把整段导孔扩成 1.4 mm，否则会失去 M1 咬合。
6. 装回屏幕，四颗 M1 轻轻拧到位即可。未经深度复核不要使用超过 2.5 mm 的螺丝，也不要对玻璃施压。
7. 固定 PCB、绝缘电池并留足排线余量后，逐一扣合面盖卡扣。合不上先检查干涉，不要强压电池或屏幕。

BOOT / EN 是维护键，前盖只开放 NEXT / PREV / OK / BACK 四颗日常键。PCB 固定柱的规格独立于压框 M1 固定，不要把所有固定孔都当作同一规格。

## 重新生成

脚本按路径相对自身定位，不再依赖维护者下载目录。安装 `source/requirements.txt` 后，在 source 目录运行：

```powershell
python .\build_enclosure.py
python .\verify_and_preview.py
```

`parameters.json` 中 PCB 参考路径指向仓库 `hardware/reference/BB2V1.step`，卡扣参考为 `reference_BBV3.step`。生成文件进入 source 下的 `deliverables/`，不会自动覆盖仓库 `print/` 与 `step/` 发布文件。检查通过后再手动替换要发布的文件。

当前刻字脚本使用 Windows Arial Bold 字体。其他系统需提供合适字体并调整 `fontPath`；仓库没有附带字体文件。

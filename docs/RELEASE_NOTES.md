# 当前版本摘要

## 固件 v2.8.0

- 兼容 4MB / 16MB 设备，共用后续 OTA 应用镜像。
- 16MB 内容分区扩展为 12.625 MiB，4MB 保留 640 KiB 配置。
- 网页分开显示物理 Flash 容量与内容分区容量，提示旧分区扩容需求。
- 电子书和词库分块上传，失败保留旧文件，使用稀疏索引减少 RAM 占用。
- 保留 NEXT / PREV / OK / BACK 映射和当前屏幕方向。
- 提供容量识别、整片备份与受支持布局的串口迁移工具。

OTA 不能替换分区表；16MB 扩容要先完成一次串口迁移。`--fresh` 与默认保留数据迁移不是同一个操作。

## 外壳 v3

- 放宽屏幕槽到 60.2 × 31.2 mm，窗口保持 55 × 26 mm。
- 压框取消方形插入槽，采用四颗 M1 直接拧塑料固定。
- 缩短键帽下裙边 0.3 mm，上部增加 0.6 mm，扩大导向活动余量。
- 凹刻字号 4 mm、深 0.6 mm。
- 底壳与 v2 几何保持一致。

## 仓库整理说明

InkMate 保留当前发布源码与设计文件，旧版发布文件归档在仓库外。Arduino 工程名、热点和固件包前缀沿用历史命名。

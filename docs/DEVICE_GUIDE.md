# 本体操作指南

InkMate 使用四颗日常按键：NEXT、PREV、OK、BACK。固件包含 **24 项应用功能**，加上首页和 Wi-Fi 二维码页，一共 **26 个页面**。在网页“设备”标签中可以选择日常显示的功能。

## 一、按键对应

| 按键 | PCB 位号 | GPIO | 常规操作 |
| --- | --- | --- | --- |
| NEXT | SW4 | 32 | 下一个功能；阅读中为下一页 |
| PREV | SW8 | 25 | 上一个功能；阅读中为上一页 |
| OK | SW5 | 33 | 执行当前页面操作 |
| BACK | SW2 | 26 | 返回首页，或退出当前操作 |

SW1 接 ESP32 EN，用于复位；SW6 接 GPIO0，用于进入串口下载模式。这两个是维护按键，前盖只开放四颗日常键。

## 二、切页、返回与清屏

- 按 NEXT / PREV 按菜单顺序切换功能，网页中隐藏的功能会被跳过。
- 普通功能页按 BACK 回到首页。
- 在首页按 OK 进入已启用的“今日运势”。
- 在首页再按 BACK 清屏，按任意一颗功能键回到首页。
- 清屏状态下网页服务继续运行。

## 三、阅读电子书

1. 在网页 **内容 → 电子书** 上传 TXT、Markdown 或 DOCX。
2. 在本体切到“电子书”，查看书名和文本大小。
3. 按 OK，从第 1 页开始。
4. NEXT 下一页，PREV 上一页。
5. OK 或 BACK 退出阅读，回到电子书介绍页。

设备存放一份当前书籍，上传新书会替换它。每次重新按 OK 开始阅读，都从第 1 页显示；阅读页底部显示当前页码。

## 四、背单词

### 开始学习

1. 在网页“概览”同步时间。
2. 选择六级高频或雅思核心词库，设置每日新词数量，保存学习计划。
3. 在本体切到“背单词”，查看已学数量、今日待复习和新词完成数。
4. 按 OK 开始当前批次。

### 回忆与评分

先显示英文单词，用一会儿时间回忆释义，再按 OK 显示中文。显示释义后按以下方式评分：

| 按键 | 评分 | 下一步 |
| --- | --- | --- |
| PREV | 忘记 | 回到较早学习阶段，安排明天复习 |
| OK | 模糊 | 安排 2 天后复习 |
| NEXT | 认识 | 提升阶段，逐步延长复习间隔 |
| BACK | 退出 | 回到学习统计页 |

“认识”的复习间隔随阶段变化，最长 60 天；首次选择“认识”的新词安排 4 天后复习。每次评分后立即保存该词进度，并进入下一词。

到期复习排在前面，随后是当天剩余新词。每批最多 96 词；一批完成后，再按 OK 可以继续剩余任务。每日新词范围 5～30，默认 10，新词目标和到期复习分别计算。

### 切换和替换词库

六级与雅思分别保存学习进度，在网页切换词库后，本体使用所选词库。网页 **内容 → 词库文件** 可用自己的 TSV 替换其中一套；替换会重置该套记录。

## 五、时钟和日期

时钟页显示日期与时间，每 10 秒刷新。可以从网页点击“同步手机时间”，也可以在本体操作：

1. 时钟页按 OK，进入设置。
2. NEXT 增加当前数值，PREV 减少。
3. OK 依次确认年、月、日、时、分。
4. 确认分钟后写入 PCF8563，秒数归零。
5. 设置中按 BACK 取消。

## 六、番茄钟

- 专注阶段 25 分钟，休息阶段 5 分钟。
- OK 开始或暂停当前倒计时。
- 倒计时进行中或暂停后，BACK 重置当前阶段；在初始状态再按 BACK 返回首页。
- 专注结束时增加完成次数、振动提示并切换到休息阶段；按 OK 开始休息。
- 休息结束后切回专注阶段，按 OK 开始下一轮。
- 离开番茄钟页面后，已经启动的倒计时继续运行。

## 七、待办、喝水与心情

### 待办事项

通过网页添加、编辑或删除，最多保存 12 条。本体显示完成数量和前 3 条内容；每按一次 OK，按列表顺序完成下一条未完成事项。

### 喝水记录

每按一次 OK 记一杯，按网页设置的每杯容量换算饮水量。默认每杯 250 ml、每日目标 2000 ml，屏幕显示杯数、总量和进度。按 RTC 日期换日清零，网页也可以手动重置。

### 心情指示器

按 OK 在开心、平静、一般、疲惫、焦虑、愤怒、难过之间循环切换，显示对应文字和表情。也可以在网页选择心情并同步。

## 八、三餐提醒

根据 RTC 时间显示用餐提示：

| 餐次 | 时间段 |
| --- | --- |
| 早餐 | 06:30～09:30 |
| 午餐 | 11:30～14:00 |
| 晚餐 | 17:30～20:30 |

设备在对应时间段内检查，每餐每天提醒一次，振动并切到三餐提醒页。需要保持当前阅读或学习不受提醒打断时，可在网页“设备”中隐藏“三餐提醒”并保存。

页面按 OK 刷新提示，也会每分钟更新。

## 九、图片、设备状态和 Wi-Fi

- **我的图片**：显示网页上传的当前黑白图，按 OK 刷新。上传时可裁切、缩放、旋转、二值化或抖动处理。
- **设备状态**：查看固件版本、运行与连接信息，按 OK 刷新。
- **Wi-Fi 二维码页**：显示热点二维码、名称、密码和管理地址。设备上电后热点自动运行，切到其他页面也可继续使用网页。

## 十、趣味工具

在这些页面按 OK 即可重新抽取或刷新结果：

| 功能 | 内容 |
| --- | --- |
| 今日运势 | 当日签文和提示 |
| 塔罗牌 | 单张牌、正逆位、含义与建议 |
| 今天吃什么 | 食物候选中随机推荐 |
| 今天喝什么 | 饮品候选中随机推荐 |
| 六面骰子 | D6 点数 |
| 二十面骰子 | D20 点数和判定 |
| 抛硬币 | 正面或反面 |
| 随机数 | 1～100 |
| 今日关键词 | 关键词与简短提示 |
| 是非神谕 | 方向提示和建议 |
| 猜拳 | 石头、剪刀、布 |
| 今日宜忌 | 宜做和暂缓的事项 |
| 幸运坐标 | 数字、方位、颜色 |
| YES / NO | 明确的随机二选一 |

食物与饮品的候选通过网页修改，保存后按新候选进行推荐。
